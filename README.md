# SSS2026

## Laboratorio 1 – Git e GitHub
- Utilizzo dei comandi Git (`add`, `commit`, `push`, `pull`)
- Creazione e gestione dei branch
- Esecuzione di merge fast-forward (riga 5)
- Esecuzione di merge tra branch
- Lavori condivisi tra collaboratori
- Creazione e gestione dei conflitti di merge
- Risoluzione manuale dei conflitti

## Laboratorio 2 – Dockerfile
- Creazione di un Dockerfile basato su `nginx:alpine`
- Build dell'immagine associata al Dockerfile
- Creazione e avvio di un container
- Test dei principali comandi della Docker CLI

## Laboratorio 3 – Dockerfile per backend e frontend
- Creazione del Dockerfile per il backend
- Creazione del Dockerfile per il frontend
- Build manuale delle immagini Docker
- Avvio separato dei due container tramite `docker run`

## Laboratorio 4 – Docker Compose e Reverse Proxy
- Creazione di un Dockerfile per il backend Python/FastAPI
- Creazione di un Dockerfile per il frontend Angular
- Build delle immagini Docker per frontend e backend
- Creazione del Dockerfile per il reverse proxy
- Configurazione del reverse proxy tramite `nginx.conf`, definendo le regole di instradamento delle richieste
- Creazione del file `docker-compose.yml` per definire e gestire i servizi (frontend, backend e reverse proxy)
- Avvio coordinato dei container tramite Docker Compose
